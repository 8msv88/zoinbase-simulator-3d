# Zoinbase Simulator 3D

Satirical social-engineering desk game. Single-file HTML + Three.js (r160).

## Play

Open [index.html](index.html) in any modern browser — no build step, no install.

## Controls

- **Drag** — orbit camera
- **Scroll** — zoom
- **Click the burner phone** — dial next mark
- Dialogue choices appear at the bottom
